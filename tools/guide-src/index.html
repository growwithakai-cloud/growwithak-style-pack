How to use it

You need Claude Code (the Code tab in the Claude desktop app) on a computer. Setup is once, about 5 minutes.

1

Get the Style Pack

You already have it. Open the Claude app, click the Code tab, drag the zip in and say:

install this skill for me
2

Film one take

Vertical, good light, a plain wall above your head. Say the trigger words out loud: orbit, background, zoom in, split, before and after, phase one, comment ___…

3

Pick your styles

Tap "+ Add this style" below, then "Copy prompt". Or say show me the growwithak styles to open this page any time.

4

Paste and approve

Paste the prompt with your video path. Claude cuts the pauses, shows a mockup, then renders 4K when you say yes.
